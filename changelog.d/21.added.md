Account-object introspection for the Snowflake backend: `list_databases()`, `list_schemas(database=None)`, `list_warehouses()` and `get_table_storage_metrics(table_name, schema=None)` on both the sync and async introspectors, with `databases` / `schemas` / `warehouses` added to the `introspect` CLI subcommand. Every statement is built as an expression tree (`SnowflakeDatabaseListQueryStatement`, `SnowflakeSchemaListQueryStatement`, `SnowflakeWarehouseListQueryStatement`, `SnowflakeTableStorageMetricsQueryStatement`) rendered by the dialect's `format_*_query_statement` methods, so no SQL text is assembled by concatenation. `SHOW WAREHOUSES` is used because no `INFORMATION_SCHEMA.WAREHOUSES` view exists. See `examples/introspection_account_objects.py` for a runnable walkthrough.
