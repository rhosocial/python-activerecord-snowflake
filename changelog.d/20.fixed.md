`SnowflakeCreateMaterializedViewExpression` now extends the core `CreateMaterializedViewExpression`, so the generic materialized view API works on Snowflake instead of raising `AttributeError: 'CreateMaterializedViewExpression' object has no attribute 'as_query'`. Existing `name=` / `as_query=` / `column_list=` usage is unchanged. `TABLESPACE` and `WITH (storage_parameter)` are now rejected with `UnsupportedFeatureError` rather than being silently dropped, and `OR REPLACE` together with `IF NOT EXISTS` is rejected up front as Snowflake requires.
