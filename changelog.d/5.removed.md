Remove the bare-name and ad-hoc namespace arguments from the Snowflake TYPE and DATABASE statement expressions: `SnowflakeCreateDatabaseExpression` now takes a `Database`, `SnowflakeCreateTypeExpression` / `SnowflakeAlterTypeExpression` / `SnowflakeDropTypeExpression` take a `Type`, and the `type_name` / `database_name` / `schema_name` arguments are gone because the object carries the namespace; the misspelled `supports_sequences` probe was also removed, replaced by `supports_sequence`.
