## Overview

This backend binds the ActiveRecord model to Snowflake, a hosted cloud data
warehouse. The documentation covers connection and account configuration,
Snowflake-native data types and operations (`VARIANT` / `ARRAY`, time travel,
`MERGE`), three-part naming, capability gates, introspection, and testing.

For the main ActiveRecord framework documentation, visit the
[core library docs](https://github.com/rhosocial/python-activerecord/tree/main/docs/en_US).
